# UI System

Esta carpeta concentra la base visual reusable de Myfit.

## Objetivo

- evitar estilos hardcodeados pantalla por pantalla,
- centralizar tokens visuales,
- reutilizar cards, headers, CTAs y scaffolds premium,
- facilitar el rediseño completo de pantallas sin duplicar lógica visual.

## Estructura

- `theme/`
- `widgets/`

## Pantallas que ya usan esta base

- `welcome / splash`
- `dashboard`

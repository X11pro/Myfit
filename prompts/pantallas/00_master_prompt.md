# Master Prompt

```text
Design a complete, premium, production-ready mobile app UI system for a fitness and nutrition app called Myfit.

This app must feel monetizable, desirable, and clearly more polished than a hobby project.
It should look like a serious product that users would trust, return to daily, and potentially pay for.

The app is not a generic calorie tracker.
It is a personal energy balance app that combines:
- food logging
- barcode nutrition lookup
- AI meal photo analysis
- editable ingredients and meal weight
- manual gym workout logging
- workout session and rest timers
- daily weight tracking
- progress tracking
- simple coaching-style daily guidance
- account/authentication

The app’s core daily question is:
“Am I eating the right amount for my goal, considering my training, work activity, and daily life?”

Design objective:
Create a mobile experience that feels:
- premium
- modern
- calm
- intelligent
- minimal
- fitness-focused
- trustworthy
- practical
- high-retention
- implementation-ready

This app must not feel:
- generic
- cluttered
- template-based
- over-decorated
- flashy
- social-media-like
- AI-generated in a cheap way
- like a beginner dashboard
- like a finance app
- like a medical app
- like a toy

Visual identity:
- dark theme first
- soft colors on deep dark backgrounds
- low saturation palette
- elegant contrast
- excellent readability
- soft modern premium feeling
- strong spacing discipline
- minimal shadows
- clean surfaces
- refined card system
- clear hierarchy
- slightly rounded corners
- sophisticated typography
- restrained use of accent colors

Color direction:
- base background: deep charcoal / near-black
- primary accent: soft muted blue
- success/healthy: calm muted green
- warning: muted amber
- destructive: restrained red
- neutral surfaces: dark layered grays
- avoid oversaturated colors
- avoid rainbow dashboards
- avoid hard neon

Typography direction:
- modern
- strong readability
- headline hierarchy should feel intentional
- data should be legible at a glance
- avoid tiny labels
- avoid oversized decorative headings
- the UI should feel premium and efficient

Create a full product system, not isolated pretty screens.
```

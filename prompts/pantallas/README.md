## Nota de uso

- Stitch responde mejor si se le pide una pantalla nueva, no si se le pide modificar una ya generada.
- El siguiente punto de diseño al retomar es revisar la hilera superior de pantallas aprobadas y decidir para cada una: `usar`, `descartar`, `repetir`.

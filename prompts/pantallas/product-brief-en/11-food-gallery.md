# Food gallery and history · `/food/gallery`

Design Myfit’s saved-meal review screen, reached from Add meal. Each entry card should identify the meal, date, calories, and available macros. Include a thumbnail only if a photo exists and confidence only when AI analysis applies. Manual meals belong in the same history.

Expose Edit and Delete without letting destructive controls dominate the list. Edit should open the existing entry rather than start a duplicate. Distinguish an empty gallery from a meal whose image cannot be loaded. Provide a first-meal action and avoid placeholder photos that could be mistaken for user data.

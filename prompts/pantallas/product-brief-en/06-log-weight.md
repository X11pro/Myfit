# Log daily weight · dashboard dialog

Design the compact dialog opened from Myfit’s Current weight card. Show a labeled numeric input with kg, the context that this is a daily entry, and explicit Cancel and Save actions.

Show keyboard entry, validation for an invalid value, and saved feedback. Cancel must leave the previous record intact. A saved weight feeds the dashboard and weight history. Guest data is local; authenticated weight records support remote persistence. Do not imply a smart-scale reading, fabricate a comparison, or treat an absent value as zero.

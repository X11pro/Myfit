# Chrome Routine Builder · connection settings

Design the options page for Myfit’s companion Chrome extension. A single connection card needs two labeled fields: Supabase project URL and public anonymous/publishable key. Explain where these values belong and why the project must match the mobile app. Explicitly say never to enter a service-role key or other privileged secret.

Provide Save connection, inline validation, a saved confirmation, and guidance to reopen the popup and sign in. Configuration is local to the browser extension; saving it does not authenticate a user. Match Myfit’s blue-gray cards and mint primary button, with full keyboard navigation.

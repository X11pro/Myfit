# Add or edit sets · workout dialog

Design Myfit’s detailed set-entry dialog. Select a muscle group, choose an exercise from the catalog or enter a custom exercise, then specify repetitions and weight in kg. Support recent exercise suggestions and multiple identical sets when adding. Keep optional perceived effort (RPE) secondary.

Differentiate adding sets from editing an existing set. Show numeric validation, Save and Cancel, and enough space above the mobile keyboard. On return, the exercise card should reflect the edit; common KG/REPS corrections also work inline. Neither saving nor repeating a set starts the rest timer.
